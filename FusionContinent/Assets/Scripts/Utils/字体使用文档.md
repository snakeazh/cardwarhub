# TMP 字体使用文档

本文说明 FusionContinent 项目的 TextMeshPro 字体资产、字号约定、TextStyle 用法，以及 Editor 生成菜单。

---

## 1. 字体资产一览

| 用途 | 源字体 | TMP 资产路径 | 模式 | 说明 |
|------|--------|--------------|------|------|
| 正文 / 通用 UI | `Assets/Fonts/GameFont.otf` | `Assets/Res/Fonts/GameFont.asset` | Static 常用字子集 | 英文字母/符号 + `Res/Config/Json` 字符串中的文字与数字 |
| 固定大标题 | `Assets/Fonts/GameFont.otf` | `Assets/Res/Fonts/GameTitleFont.asset` | Static | 仅烘焙标题用字，配合字号 60 |
| 关卡艺术字 | `Assets/Fonts/ZhuoTeZiYouTi.otf` | `Assets/Res/Fonts/StageNameText.asset` | Static | 主界面关卡名，字集来自 StageBattleConfig |

全局 TextStyle 表：

- `Assets/Res/UIConfig/TextStyleSheet.asset`（已设为 TMP Settings 默认 Style Sheet）

运行时样式工具：

- `Assets/Scripts/Utils/TextMeshProTools.cs`

## 2. 字号与 TextStyle 约定（拼界面必读）

### 2.1 正文（普通字体）

- **Font Asset**：`GameFont`
- **Font Size（基准）**：固定填 **36**
- **Text Style**：用 Style 控视觉字号，不要直接改成 30/48

| Text Style | 相对基准 | 视觉字号 | 典型用途 |
|-----------|----------|----------|----------|
| `Content30` | 83% | 30 | 辅助说明、次要标签 |
| `Content36` | 100% | 36 | 正文 / 默认 |
| `Content48` | 133% | 48 | 小标题、按钮主文案 |

兼容保留（旧界面可能仍在用）：`Content24`、`ButtonSmall` / `ButtonMiddle` / `ButtonLarge` 等，新界面优先用上表三档。

### 2.2 固定大标题

- **Font Asset**：`GameTitleFont`（不要用 GameFont 硬放大）
- **Font Size（基准）**：固定填 **60**
- **Text Style**：`TitleDialog60`（样式本身不再二次缩放字号）

### 2.3 关卡艺术字（主界面 StageName）

- **Font Asset**：`StageNameText`
- 颜色：配置表 `StageNameColor1` / `StageNameColor2`（渐变 + 描边 Underlay）
- 由菜单工具写回主界面预制体，一般不手改

### 2.4 Inspector 检查清单

1. Style Sheet 留空 → 走全局 `TextStyleSheet`
2. 正文：`GameFont` + Size **36** + `Content30/36/48`
3. 标题：`GameTitleFont` + Size **60** + `TitleDialog60`
4. 不要：正文 Size 乱写；标题 Size=36 再叠旧版 167%（已废弃）

## 3. 拼界面 vs 写代码

| 场景 | 做法 |
|------|------|
| 预制体字号/字体已定 | **只在 Inspector 配置**，不必写代码 |
| 运行时改正文档位 | `TextMeshProTools.SetFontSize(tmp, GameFontSize.M)` |
| 运行时套固定标题 | `TextMeshProTools.ApplyTitleFont60(tmp)` |
| 仅换 Style 名 | `TextMeshProTools.ApplyTextStyle(tmp, "Content30")` |
| 渐变色 | `TextMeshProTools.SetTMPVerticalGradient(...)` |
| 描边 Underlay | `TextMeshProTools.SetUnderlayColor(...)` |
| 通用按钮文案样式 | `UICommonBtn` / `ButtonData.TextStyle`（与 Style 名对应） |

`GameFontSize` 枚举：

- `S` → Content30（视觉 30）
- `M` → Content36（视觉 36）
- `L` → Content48（视觉 48）

## 4. Editor 菜单（生成 / 更新字体）

在 Unity 菜单 **Tools → Fonts**：

| 菜单 | 作用 |
|------|------|
| 生成 GameFont 常用字 Static 子集 | 收集 ASCII + Json 配置用字，生成/更新 `GameFont.asset`，并设为 TMP 默认字体 |
| 生成 GameTitleFont 固定标题字体 | 读取标题字集，生成/更新 `GameTitleFont.asset` |
| 生成 StageNameText 字体并应用到主界面 | 收集关卡名用字，更新字体并写回主界面 StageNameText |

### 4.1 GameFont（常用字 Static）

字集来源：

1. `Assets/Fonts/Number.txt`：数字、英文字母、常用符号（文件缺失时用内置 ASCII 兜底）
2. `Assets/Res/Config/Json/*.json`：所有 JSON 字符串值中的文字与数字（自动去重）

生成结果：

- 输出 `Assets/Res/Fonts/GameFont.asset`（Dynamic 烘焙后切 **Static**）
- Sampling Point Size：72；Atlas：2048 + Multi Atlas
- 同时写出预览字集 `Assets/Fonts/GameFontCharacters.txt` 便于核对
- 配置表文案变更后需重新执行菜单

注意：仅覆盖配置表里出现过的字；纯运行时拼接、未进表的罕用字可能缺字。

### 4.2 GameTitleFont

1. 编辑 `Assets/Fonts/GameTitleCharacters.txt`  
   - `#` 开头为注释  
   - 其余行写入所有会用到的 **60 号标题文案**（自动去重）
2. 执行「生成 GameTitleFont 固定标题字体」
3. Sampling：90；烘焙后切 Static
4. 确认 YooAsset 可加载地址：`Fonts_GameTitleFont`  
   - 也可启动时 `TextMeshProTools.SetTitleFontAsset(font)` 预缓存

### 4.3 StageNameText

- 字集：`tbstagebattleconfig.json` 的 `StageName`
- 源字体：ZhuoTeZiYouTi，Sampling：108
- 应用目标：`MainInterfacePanel` 上名为 `StageNameText` 的 TMP

## 5. 资源与加载约定

| 资源 | 建议 Address / 说明 |
|------|---------------------|
| GameFont | TMP 默认字体；新 Text 默认跟随 Settings |
| GameTitleFont | `Fonts_GameTitleFont` |
| StageNameText | 主界面预制体直接引用即可 |
| TextStyleSheet | TMP Settings → Default Style Sheet |

描边颜色运行时请改 `fontMaterial`（实例材质），不要改 `fontSharedMaterial`，避免污染共享资产。标题/关卡名字体材质需开启 Underlay，否则 `_UnderlayColor` 不生效。

## 6. 常见问题

**Q：标题看起来约 100 号？**  
A：组件 Font Size 写成了 60，同时又用了旧的 `<size=167%>`。请确认 Style 表里 `TitleDialog60` 已为空定义，且 Size=60。

**Q：正文改成 Font Size=30 行不行？**  
A：新规范不要。保持 36 + `Content30`，方便全局调 Style。

**Q：GameTitleFont 缺字？**  
A：把缺的标题文案补进 `GameTitleCharacters.txt`，重新跑生成菜单。

**Q：颜色 / 字号逻辑写在哪？**  
A：统一放 `TextMeshProTools`，业务面板不要散落魔法数字。
