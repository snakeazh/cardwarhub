## 一、整体架构

### 1.1 架构分层

```
ISkill (接口层)
    │
    └── SkillBase (抽象基类)
            │
            ├── 45个具体技能实现
            │       │
            │       ├── ObjectPoolManager (对象池，发射子弹/特效)
            │       │
            │       └── 子弹/特效组件 (MonoBehaviour)
            │               │
            │               ├── 碰撞检测 (OnTriggerEnter/Stay, Raycast)
            │               ├── 伤害施加 (DamageSystem)
            │               ├── 效果应用 (击退、击飞、Buff)
            │               └── 对象回收 (对象池)
```

### 1.2 核心类说明

| 类名 | 说明 |
|------|------|
| `ISkill` | 技能接口，定义释放/初始化契约 |
| `SkillBase` | 所有技能的抽象基类，管理冷却、伤害计算、暴击、Buff |
| `SkillNodeConfig` | 技能图节点配置（编辑器用） |
| `SkillGraphConfig` | 技能图配置容器 |

### 1.3 技能分类总览

| 类别 | 技能列表 |
|------|----------|
| **方向斩击类** | 瞬袭斩、重劈斩、重击斩、破军一击、圆舞斩、次元斩、幽邃之墙、超级斩、爆炎斩、通用划斩 |
| **投射物类** | 普通攻击、电幻法球、风暴穿刺、火球术、火球术攻击、风暴之灵、魔影轰杀、暗夜彗星、天流斩 |
| **区域/持续类** | 风之箭雨、风舞疾袭、雷霆领域、魔法震荡、能量迸发、旋风斩 |
| **治疗/Buff类** | 抚痕灵愈、慰灵圣咏、能量倾注、月影盾、祈愿 |
| **特殊类** | 魔法射线、暗影法阵、死神挥砍、圣光坠落、月神诅咒、疾风骤雨、裂空风刃 |

## 二、SkillBase 抽象基类

**文件：** `Assets/Scripts/Game/Skill/SkillBase.cs`

### 2.1 核心属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `Id` | `int` | 技能标识符 |
| `Level` | `int` | 技能等级 |
| `Type` | `SpecialEffectType` | 技能类型枚举 |
| `Parent` | `SoldierCard` | 施放技能的士兵 |
| `Buffs` | `BuffManager` | Buff管理器 |
| `Attributes` | `AttributeSet` | 属性集（技能属性/士兵属性/模块属性） |
| `Config` | `SpecialEffectsConfig` | 技能配置数据 |

### 2.2 核心方法

| 方法 | 签名 | 说明 |
|------|------|------|
| `Initialize` | `(SoldierCard parent, int level, SpecialEffectsConfig cfg)` | 初始化技能，注入基础数据，分类属性（Skill/Soldier/Module），设置Buff |
| `IsReady` | `(bool isActiveRelease)` | 检查技能是否就绪（冷却是否结束） |
| `ReleaseSkill` | `()` | 处理冷却计时和冷却显示更新 |
| `GetCooldownTime` | `(bool isSpeedMultiplier = true)` | 获取冷却时间，可选受游戏速度倍率影响 |
| `Cast` | `(object obj)` | 公开释放方法，内部调用 `OnCast(obj)` |
| `OnCast` | `(object obj)` | **抽象方法**，由各技能实现具体逻辑 |
| `SumDamageTypes` | `()` | 计算伤害分项（物理/魔法/真实）并返回字典 |
| `GetCriticalDamage` | `()` | 计算并应用暴击逻辑，返回暴击倍率 |
| `GetLaunchSpeed` | `()` | 获取子弹飞行速度 |

### 2.3 属性读取模式

技能通过 `Attributes.GetFinal(...)` 从属性集中读取配置，常见属性如下：

| 属性名 | 含义 |
|--------|------|
| `SkillBasicAttackPower` | 基础攻击力 |
| `SkillRange` | 技能范围（决定特效Scale） |
| `SkillDuration` | 持续时间 |
| `SkillContinuousAtkNum` | 连续攻击次数 |
| `SkillContinuousAtkSpeed` | 连续攻击速度 |
| `SkillSpellInheritance` | 法术威力继承倍率 |
| `SoldierBulletSizeCorrection` | 子弹尺寸修正 |
| `SoldierAttackPower` | 士兵攻击力 |
| `SoldierSpellPower` | 士兵法术强度 |

## 三、子弹/特效组件系统

### 3.1 组件总览

技能通过 **对象池** 发射 GameObject，GameObject 上挂载 `MonoBehaviour` 组件来处理碰撞、伤害和效果。

```
子弹组件 (按复杂度从高到低)
│
├── ProjectileBullet          (新设计，最完善：穿透、弹墙、屏幕边界检测)
├── DrawSlashBullet           (触发器伤害 + 击退/击飞 + 命中特效)
├── MagicianLaserCannonAttack (持续激光束 + 左右扫描)
├── MagicianShadowFormation   (圆形触发器 + 周期性伤害 + 聚怪)
├── TornadoProjectile         (移动 + 持续伤害 + 随机游荡)
├── WallReboundBullet         (Raycast碰撞 + 墙体反弹 + 敌人射线伤害)
├── ArrowBullet              (BoxCast检测 + 周期性伤害 + 摄像机抖动)
├── FireballDropEffect       (抛物线下落动画)
├── SkyFlowBullet            (BoxCast + 3连击)
├── ThunderFieldFullScreenEffect (区域收集 + 随机落雷)
├── WindDanceAttackEffect    (周期性 + 友方位置特效)
├── CdTimeEnergyBurstController (持续时间 + CD时间管理)
├── BulletFiringCollisionEffect  (简单触发 + 离屏检测)
├── FireBallController       (简单触发伤害)
└── SpearmenReaperSlash      (拉拽怪物到屏幕底部)
```

### 3.2 ProjectileBullet（最完善投射物）

**文件：** `ProjectileBullet.cs`

功能最完整的子弹组件，支持：

- **定向飞行**：根据传入方向飞行，支持速度设置
- **穿透模式**：`isPenetrate` + `maxPenetrateCount`，可穿透多个敌人
- **墙体弹跳**：`isBounce` + `maxBounceCount`，可弹墙反弹（使用 `Vector2.Reflect` 计算反射方向）
- **击飞/击退**：`knockUpVal`（垂直击飞）、`repelMonsterVal`（水平击退）
- **屏幕边界检测**：超过 `maxDistance`、超过 `lifeTime` 或离开屏幕时自动回收
- **命中特效**：`SpawnHitEffect` 从配置读取命中特效路径
- **对象池集成**：通过 `GenericObjectPool` 回收复用
- **事件系统**：`event Action<Vector3> OnHit` / `event Action OnComplete`

### 3.3 DrawSlashBullet（斩击类通用组件）

**文件：** `DrawBullet.cs`

大部分斩击类技能共用的子弹组件：

- 使用 **触发器碰撞** (`OnTriggerStay2D`) 检测 "HitBox" 层级的敌人
- `HashSet<string>` 记录已命中目标，防止重复伤害
- `hitTargetDuration` 控制周期性伤害（每次命中后隔多久重新造成伤害）
- 支持 `spawnHitEffectNum` 限制特效数量（移动端优化）
- 命中时调用 `SpawnHitEffect` 播放命中特效

### 3.4 MagicianLaserCannonAttack（激光炮组件）

**文件：** `MagicianLaserCannonAttack.cs`

持续激光束效果：

- 加载武器模型（`raiseHand` 节点）
- 根据方向计算旋转角度
- **递归左右扫描**：以一定角度左右摆动，覆盖更大范围
- `OnTriggerStay2D` 对区域内的怪物周期性造成伤害
- `CheckHitTargetDamage` 防止对同一目标短时间重复伤害
- 命中间隔：`0.5f` 秒

### 3.5 MagicianShadowFormation（暗影法阵组件）

**文件：** `MagicianShadowFormation.cs`

持续性法阵效果：

- `OnTriggerStay2D` 每 `1f` 秒对区域内的怪物造成伤害
- `OnTriggerEnter2D` 拉拽怪物到法阵中心（当 `isAttractTogether = true`）
- 使用 `Dictionary<string, float>` 记录每个怪物的上次受伤时间

### 3.6 WallReboundBullet（弹墙电球组件）

**文件：** `WallReboundBullet.cs`

电球在墙体间反弹：

- 使用 `Physics2D.Raycast` 检测墙体和敌人
- 墙体命中后用 `Vector2.Reflect` 计算反射方向
- `enemyLayer` 检测命中敌人（射线检测）
- `isWallRebound` 控制是否启用弹墙
- `hashSet` 防止重复伤害

### 3.7 TornadoProjectile（龙卷风组件）

**文件：** `TornadoProjectile.cs`

龙卷风飞行并持续伤害：

- 使用 DOTween 控制飞行路径
- 飞行中遇到怪物后，切换为随机游荡模式（`StartMoving`）
- 游荡模式：随机方向飞一段 → 等待一段 → 重复
- `damageSequence` 控制多段持续伤害
- `HashSet<MonsterCard>` 防止重复命中

### 3.8 ThunderFieldFullScreenEffect（全屏落雷组件）

**文件：** `ThunderFieldFullScreenEffect.cs`

大范围区域内的随机落雷：

- `OnTriggerStay2D` 持续收集区域内的怪物到 `HashSet`
- 每隔 `hitTargetDuration` 秒，从集合中随机选一个怪物降下雷电
- 雷电使用 `ArrowBullet` 组件（固定闪电伤害）

## 四、各技能实现详解

### 4.1 方向斩击类

#### 瞬袭斩 (SwiftAssaultSkill)

- 从 `SkillRange` 获取Scale
- 从配置获取突袭偏移量（`assault_offset`）
- 循环 `continuousDamageNum` 次，以 0.1s 间隔生成子弹
- 子弹使用 `DrawSlashBullet`，带击退值

#### 爆炎斩 (FlamingBurst)

- 多波次多叉路火球：每轮间隔 `0.2s`，每轮从基准位置分裂出左右火球
- `exlevel` 控制叉路数量（1=仅正面，2=+左，3=+右）
- `forkAngle` 控制左右分裂角度（默认10度）
- 总共 `8` 轮，每轮前进 `2f` 单位

#### 圆舞斩 (CircularDanceSkill)

- `SkillContinuousAtkNum` 控制连击次数（+1额外一击）
- `SkillContinuousAtkSpeed` 控制连击间隔
- 第一击：spawn到自身上方，使用 `DrawSlashBullet`
- 后续每一击：spawn到自身位置，向前方移动一段距离

#### 超级斩 (SuperSlashAttackSkill)

- 使用旧版资源加载（`ResourceLoader.LoadSync`）而非对象池
- 在子节点路径 `eff_js_ts03/ani_js_ts03/box` 上查找 `RaiseHand` 组件
- 播放举刀动画（类似前摇）

#### 次元斩 (DimensionalSlashSkill)

- `SkillRange + 200` 作为Scale
- 子弹使用 `BoxCollider2D`，在 3s 后关闭碰撞器
- 4.2s 后回收（给予足够动画时间）

#### 死神挥砍 (ReaperSlashAttackSkill)

- 第一段：钩锁效果，使用 `SpearmenReaperSlash` 组件，将怪物拉向屏幕底部
- 0.5s 后第二段：镰刀横扫，使用 `OnTriggerAttackDamage` 组件

#### 通用划斩 (DrawSlash)

- 通用型斩击波，支持Scale/Speed/Distance参数化配置
- 使用 DOTween `DOMove` 控制飞行路径

---

### 4.2 投射物类

#### 普通攻击 (NormalAttackSkill)

- 基础攻击，从 `Config.ProjectileName` 获取投射物
- 使用士兵 `SoldierBulletSizeCorrection` 修正子弹大小
- 特殊处理：弓箭手(Spearmen)、刺客(Assassin) 使用专属投射物
- 特殊处理：万剑技能(Spearmen_Wanjian) 使用拖尾箭头
- 最终调用 `Projectile.Launch()`

#### 电幻法球 (MagicElectricBallSkill)

- 从 `SkillRange` 获取Scale，`SkillDuration` 获取持续时间
- 使用 `WallReboundBullet` 实现墙体反弹
- 计算旋转角度使电球朝向移动方向

#### 火球术 (FireBallSkill)

- 优先使用 `ProjectileBullet`（新组件，支持穿透等特性）
- 如果场景中没有 `ProjectileBullet` 组件，降级为纯 DOTween 移动
- 命中时调用 `OnFireballHit`，生成爆炸特效

#### 暗夜彗星 (DarkCometSkill)

- 递归模式：多波次天降陨石，每波间隔 `0.2s`
- 使用 `FireballDropEffect.Play()` 实现抛物线下落
- 命中后调用 `DrawSlashBullet` 生成爆炸圈

#### 天流斩 (SkyFlowAttackSkill)

- 每次从属性计算伤害分项（物理/魔法/真实）
- 使用 `SkyFlowBullet` 组件，实现 3 连击（每次间隔 `0.2s`）

#### 魔影轰杀 (ShadowBlastSkill)

- 递归模式：多波次投射，每波间隔 `0.2s`
- 使用 `BulletFiringCollisionEffect` 发射爆炸弹头
- 命中时切换为 `DrawSlashBullet` 爆炸圈（0.2s 后关闭碰撞器）

---

### 4.3 区域/持续类

#### 风之箭雨 (WindSwordRainAttackSkill)

- 使用 **递归 DelayedCall** 反模式避免一次性 N 个 Tween 的卡顿
- 每 `0.01s` 间隔生成一根箭矢，在 `SkillRange` 范围内随机位置
- 每根箭矢存活 `1.5s` 后回收
- 命中使用 `ArrowBullet`（固定伤害 + 摄像机抖动）

#### 风舞疾袭 (WindDanceAttackSkill)

- 使用 `WindDanceAttackEffect` 组件
- 每 `hitTargetDuration` 秒，在随机友方单位位置生成风舞特效
- 使用 `DrawSlashBullet` 并带击退值

#### 雷霆领域 (ThunderFieldFullScreenSkill)

- 全屏区域效果，使用 `ThunderFieldFullScreenEffect` 组件
- 持续 `SkillDuration` 秒
- 区域内的怪物每 `hitTargetDuration` 秒被随机选中降下雷电

#### 魔法震荡 (MagicShakeSkill)

- 递归模式：多波次落雷，每波间隔 `0.2s`
- 第一波使用 `${ProjectileName}02`，后续使用 `${ProjectileName}03`（带击飞）
- 落雷使用 `BoxCollider2D` + `DrawSlashBullet` 组合
- 0.3s 后关闭碰撞器

#### 能量迸发 (CdTimeEnergyBurstSkill)

- 使用 `CdTimeEnergyBurstController` 组件
- 设置游戏无限CD时间（`GamePlayManager.SetUnlimitedCDTime`）
- 持续时间结束后恢复CD时间（`GameLandUI.ResetCardCooldownTime`）

#### 旋风斩 (TornadoAttackSkill)

- 使用 `TornadoProjectile` 组件
- 龙卷风飞行中遇到怪物后切换为游荡模式

---

### 4.4 治疗/Buff类

#### 抚痕灵愈 (ScarHealingBalmSkill)

- 治疗量 = `SkillBasicAttackPower + (SoldierSpellPower * SkillSpellInheritance)`
- 遍历所有友方士兵，恢复生命值
- 在每个士兵位置生成 `EliaSkillSoothmark01` 特效

#### 慰灵圣咏 (RequiemChantSkill)

- 每个友方士兵：
  1. 在士兵位置生成光环特效
  2. 1s 后发射飞弹（抛物线 `DOJump`）回到施法者
  3. 动画结束后给士兵添加 `RequiemChant` Buff
- Buff使用 `AttributeModifier` 提供攻击力/攻速/法术强度加成
- Buff结束时移除属性修改

#### 能量倾注 (EnergyPouringSkill)

- 流程：举手 → 加Buff → 划斩 → 发射子弹
- Buff效果与 `RequiemChantSkill` 相同

#### 月影盾 (MoonlightShieldSkill)

- 护盾值 = `SkillBasicAttackPower + (SoldierSpellPower * SkillSpellInheritance)`
- 护盾可以叠加（`AddShield`）
- 每层护盾提供法术强度百分比加成（通过 `AttributeModifier`）
- 护盾破碎时（`ShieldBroken`）移除加成并播放破碎特效

#### 祈愿 (PraySkill)

- 独立类，不继承 `SkillBase`
- 随机选择一名友方士兵
- 读取 `PrayRandomSoldierFortify` 属性
- 应用属性修改并播放特效

### 4.5 特殊类

#### 魔法射线 (MagicianLaserCannonSkill)

- 使用 `MagicianLaserCannonAttack` 组件
- 持续 `SkillDuration` 秒
- 激光束在方向上左右扫描覆盖区域

#### 暗影法阵 (MagicShadowFormationSkill)

- 使用 `MagicianShadowFormation` 组件
- 可选聚怪模式（`isAttractTogether`）

#### 圣光坠落 (TheHolyLightFallsSkill)

- 使用 `DrawSlashBullet` 造成周期性伤害（周期 `1f` 秒）

#### 月神诅咒 (CurseOfTheMoonGodSkill)

- 最小持续 `6s`，fallback `1s`
- 使用 `DrawSlashBullet` 周期性伤害（周期 `1f` 秒）

#### 裂空风刃 (CrackedAirBladeAttackSkill)

- 委托给外部组件处理

## 五、代码模式总结

### 5.1 对象池使用模式

```csharp
// 从对象池获取
var bullet = ObjectPoolManager.Instance.Get(
    ObjectPoolManager.PoolType.Bullet,
    $"{Config.ProjectileName}01",
    spawnPos,
    Quaternion.identity
);

// 设置数据（大多数使用组件）
if (bullet.TryGetComponent<DrawSlashBullet>(out var slash))
    slash.SetStartAttack(this, duration);

// 设置完毕后的回调（DOTween动画完成后回收）
DOTween.Sequence()
    .AppendCallback(() => { /* ... */ })
    .AppendInterval(duration)
    .OnComplete(() => ObjectPoolManager.Instance.Return(bullet));
```

### 5.2 递归DelayedCall反模式（避免N个Tween一次性附加）

```csharp
// ❌ 错误：一次性附加 N 个回调会卡顿
for (int i = 0; i < arrowNum; i++)
{
    seq.AppendCallback(() => SpawnSingleArrow()); // 100个回调在同一帧附加！
}

// ✅ 正确：递归 DelayedCall，每帧只附加一个
void CreateArrowRain(...)
{
    if (spawnedCount >= arrowNum) return;
    spawnedCount++;
    DOVirtual.DelayedCall(spawnInterval, () =>
    {
        SpawnSingleArrow();
        CreateArrowRain(...); // 递归继续
    });
}
```

### 5.3 伤害施加模式

```csharp
// 通过伤害系统施加伤害
var damageData = new DamageData
{
    Source = this.Parent,
    Target = monster,
    Skill = this,
    Damage = finalDamage,
    DamageType = damageType,
    IsCrit = isCrit,
    IsPenetrate = isPenetrate,
};
monster.TakeDamage(damageData);

// 附加效果
if (monster != null && knockUpVal > 0)
    monster.KnockUp(knockUpVal, transform.position);
if (monster != null && repelVal > 0)
    monster.Repel(repelVal, transform.position);
```

### 5.4 Buff集成模式（带回调）

```csharp
// 添加Buff
var buffConfig = BuffConfigManager.Instance.Get(buffId);
this.Parent.Buffs.Add(buffConfig, OnBuffStart, OnBuffEnd);

void OnBuffStart(BuffBase buff)
{
    // 应用属性修改
    var modifier = new AttributeModifier();
    modifier.Add(new AttributeData(AttributeType.SoldierAttackPower, AttributeOperator.PercentAdd, buffValue));
    this.Parent.Attributes.AddModifier(modifier);
}

void OnBuffEnd(BuffBase buff)
{
    // 移除属性修改
    this.Parent.Attributes.RemoveModifier(modifier);
}
```

## 六、技能图节点与运行时映射

> 以下为编辑器节点类型与运行时类的对应关系
