## 一、系统概述

### 1.1 设计目标

技能与Buff系统采用**节点图（Node Graph）**架构，参考可视化脚本（Visual Scripting）和行为树（Behavior Tree）的设计思想，将技能/Buff的行为拆解为多个可组合的节点，通过有向边连接形成完整的执行图。

**核心优势**:
- **可视化编辑**: 节点图可通过编辑器扩展实现拖拽式连线编辑
- **职责分离**: 每种节点类型对应一个独立的 Handler，便于维护和扩展
- **异步支持**: 支持 `async/await`，可优雅处理投掷物飞行、引导时间等延迟操作
- **数据驱动**: 节点参数存储在 `ScriptableObject` 中，由 Luban 等表格工具生成

### 1.2 核心组件一览

| 组件 | 命名空间 | 职责 |
|------|---------|------|
| `SkillGraphConfig` | `FusionContinent.Skill.Config` | 技能图数据容器（节点列表 + 边列表） |
| `BuffGraphConfig` | `FusionContinent.Buff.Config` | Buff图数据容器 |
| `SkillNodeConfig` | `FusionContinent.Skill.Config` | 单个技能节点的配置数据 |
| `BuffNodeConfig` | `FusionContinent.Buff.Config` | 单个Buff节点的配置数据 |
| `SkillNodeExecutor` | `FusionContinent.Skill.Handler` | 图遍历执行引擎 |
| `SkillHandlerRegistry` | `FusionContinent.Skill.Handler` | 节点类型到 Handler 的单例注册表 |
| `SkillContext` | `FusionContinent.Skill.Handler` | 运行时执行上下文 |

| `BuffManager` | `FusionContinent.Buff` | Buff管理器 |
| `BuffBase` | `FusionContinent.Buff` | Buff实现基类 |

## 二、架构设计

### 2.1 整体架构

```
SkillGraphConfig (ScriptableObject)
  ├─ List<SkillNodeConfig>  nodes    ← 节点列表
  └─ List<EdgeConfig>       edges   ← 有向边列表

SkillNodeExecutor.Run()
  │
  ├─ [1] 从入口节点（Cast）开始
  │
  ├─ [2] 查找 Handler: SkillHandlerRegistry.Get(node.NodeType)
  │
  ├─ [3] 执行 Handler: await handler.Execute(node, context)
  │       │
  │       ├─ SyncHandler → 直接执行（Damage, Effect, ApplyBuff...）
  │       └─ AsyncHandler → 等待异步操作（Cast动画, Projectile, Delay...）
  │
  ├─ [4] 遍历输出边，执行后续节点
  │
  └─ [5] 循环直到所有节点执行完毕或被取消
```

### 2.2 节点类型与 Handler 映射

| 节点类型 (NodeType) | Handler 类 | 同步/异步 | 功能描述 |
|--------------------|-----------|-----------|---------|

| `Telegraph` | `TelegraphHandler` | 异步 | 显示预警指示器，持续指定时间 |
| `Projectile` | `ProjectileHandler` | 异步 | 生成投掷物，等待飞行时间 |

### 2.3 方向斩击节点设计

#### SlashWave 斩击波
- 参数: prefab, speed, distance, damage, knockback, knockup, scale
- 端口: exec_in → exec_out

#### MultiSlash 多重斩击
- 参数: slash_count, interval, direction_mode(Same/Rotate/Random), angle_offset
- 端口: exec_in → exec_out

#### ForkSlash 分裂斩击
- 参数: fork_count, fork_angle, forward_steps, step_interval
- 端口: exec_in → exec_out

#### ChargeSlash 蓄力斩击
- 参数: charge_time, charge_effect, can_move, damage_ratio
- 端口: exec_in → exec_out

#### SlashCombo 连招
- 参数: combo_count, trigger_type(Auto/Click)
- 端口: exec_in → exec_out, combo_1, combo_2...

组合示例:
- 瞬袭斩: Cast → Telegraph → MultiSlash → Effect
- 爆炎斩: Cast → ForkSlash → Effect
- 圆舞斩: Cast → MultiSlash → Effect
- 次元斩: Cast → SlashWave → Effect

### 2.4 Buff 节点类型（无独立执行引擎）

| 节点类型 (NodeType) | 功能描述 | 默认参数 |
|--------------------|---------|---------|
| `OnApply` | Buff被添加时触发 | `buff_name` |
| `OnTick` | Buff周期性触发 | `interval` = 1秒 |
| `OnRemove` | Buff被移除时触发 | — |
| `Dot` | 持续伤害（Damage Over Time） | `damage`, `interval`, `damage_type` |
| `Hot` | 持续治疗（Heal Over Time） | `heal`, `interval` |
| `Shield` | 护盾 | `shield_value` |
| `Vulnerable` | 易伤（受到的伤害增加） | `damage_increase` |
| `Slow` | 减速 | `speed_reduce` |
| `Effect` | 视觉/音效特效 | `vfx`, `sfx` |

> **注意**: Buff系统目前没有实现独立的 `BuffNodeExecutor`，Buff图的遍历执行尚未集成到 `BuffManager` 中。Buff节点图目前作为数据模板使用，实际效果由 `BuffBase` 的 `DurationType`（Once/Duration）驱动。

## 三、核心类详解

### 3.1 SkillNodeExecutor（执行引擎）

`SkillNodeExecutor` 是整个技能系统的核心，负责图的遍历执行。

```csharp
public class SkillNodeExecutor
{
    private SkillContext _context;
    private SkillGraphConfig _config;
    private HashSet<string> _executedNodes = new HashSet<string>();

    public async Task Execute(SkillGraphConfig config, SkillContext context)
    {
        _config = config;
        _context = context;
        _executedNodes.Clear();

        if (config == null || config.Nodes.Count == 0)
        {
            Debug.LogWarning($"技能配置为空");
            return;
        }

        // 从入口节点开始执行
        var entryNode = config.GetEntryNode();
        if (entryNode == null)
        {
            // 按顺序执行所有节点（兜底）
            foreach (var node in config.Nodes)
                await ExecuteFromNode(node.NodeId);
            return;
        }

        await ExecuteFromNode(entryNode.NodeId);
    }

    private async Task ExecuteFromNode(string nodeId)
    {
        if (_context.CancellationToken.IsCancellationRequested)
            return;

        var node = _config.GetNode(nodeId);
        if (node == null)
            return;

        // 防止重复执行
        if (_executedNodes.Contains(nodeId))
            return;

        _context.CurrentNodeId = nodeId;
        _executedNodes.Add(nodeId);

        var handler = SkillHandlerRegistry.Get(node.NodeType);
        if (handler != null)
        {
            try
            {
                await handler.Execute(node as SkillNodeConfig, _context);
            }
            catch (OperationCanceledException)
            {
                return;
            }
        }

        // 执行后续节点
        await ExecuteNextNodes(nodeId);
    }
}
```

**设计要点**:
- 使用 `HashSet<string>` 防止节点被重复执行（适用于包含循环引用的图）
- 支持 `CancellationTokenSource` 取消技能执行
- 支持 `Task` 异步等待，适用于动画、特效、投掷物等耗时操作
- 后续节点按顺序串行执行（不并发）

```csharp
        Register(new EffectHandler());

    }
```

### 3.7 BuffManager（Buff管理器）

```csharp
public class BuffManager
{
    private readonly Dictionary<BuffType, IBuff> _activeBuffs = new Dictionary<BuffType, IBuff>();

    // 添加Buff，支持叠加模式
    public void AddBuff(BuffBase v, bool isAdditive = false);

    // 每帧调用，更新持续时间并触发效果
    private void Update()
    {
        foreach (var key in _activeBuffs.Keys.ToList())
        {
            var buff = _activeBuffs[key];
            if (!buff.CheckDuration())
            {
                _activeBuffs.Remove(key);
                continue;
            }
            buff.AddEffectuateCount();
        }
    }

    // 获取活跃Buff（按概率筛选）
    public Dictionary<BuffType, IBuff> GetActiveBuffs();
}
```

### 3.8 BuffBase（Buff实现）

```csharp
public class BuffBase : IBuff
{
    public BuffType Type { get; set; }
    public BuffDurationType DurationType { get; set; }  // Once / Duration
    public float Value { get; set; }
    public float Duration { get; set; }
    public int EffectuateCount { get; private set; }
    public float Probability { get; set; }
    public Action<bool, object> EffectuateCallback { get; set; }
    public float Elapsed { get; set; }

    // 检查是否过期
    public bool CheckDuration()
    {
        switch (DurationType)
        {
            case BuffDurationType.Once:
                return EffectuateCount == 0;  // 生效过一次就过期
            case BuffDurationType.Duration:
                var elapsed = (DateTime.Now - CreateTime).TotalSeconds;
                return elapsed < Duration;     // 超过持续时间则过期
        }
        return true;
    }

    // 触发效果并增加计数
    public int AddEffectuateCount()
    {
        EffectuateCount++;
        return EffectuateCount;
    }
}
```

### 4.4 BranchHandler（条件分支节点）

```csharp
// 节点参数
// "condition"      : 条件类型
// "compare_value"  : 比较值（用于HpLessThan/HpGreaterThan）
// "probability"    : 随机概率（0-1，用于Random类型）

public class BranchHandler : ISkillNodeHandler
{
    public string NodeType => "Branch";
    public int Priority => 0;
    public bool IsAsync => true;

    public async Task Execute(SkillNodeConfig node, SkillContext context)
    {
        var condition = node.GetParamString("condition", "TargetAlive");
        var probability = node.GetParamFloat("probability", 0.5f);

        Debug.Log($"[BranchHandler] 条件判断: condition={condition}, probability={probability}");

        bool result = EvaluateCondition(condition, probability, context);
        Debug.Log($"[BranchHandler] 条件结果: {result}");

        // 将结果存入上下文，供后续节点使用
        context.SetExtraData("branch_result", result);
    }

    private bool EvaluateCondition(string condition, float probability, SkillContext context)
    {
        switch (condition)
        {
            case "TargetAlive":
                return context.Target != null;
            case "Random":
                return UnityEngine.Random.value < probability;
            case "TargetIsMonster":
                return context.Target?.GetComponent<MonsterCard>() != null;
            case "TargetIsSoldier":
                return context.Target?.GetComponent<SoldierCard>() != null;
            case "HpLessThan":
                var threshold = probability;
                return true; // TODO: 需接入血量系统
            case "AlwaysTrue":
                return true;
            case "AlwaysFalse":
                return false;
            default:
                return false;
        }
    }
}
```

> **注意**: 当前 `BranchHandler` 执行后仍然会执行所有后续节点，分支判断结果存入 `context.SetExtraData("branch_result", ...)` 供后续节点读取。

## 五、执行流程详解

### 5.1 完整技能执行流程（以火球术为例）

```
SkillRuntime.Execute(skillGraph, caster, target)
  │
  └─ SkillNodeExecutor.Execute(skillGraph, context)
        │
        ├─ [1] Cast 节点
        │     ├─ CastHandler.Execute() → 播放施法动画
        │     └─ 等待 castTime（1秒）
        │
        ├─ [2] Telegraph 节点
        │     ├─ TelegraphHandler.Execute() → 在目标位置显示预警圈
        │     └─ 等待 duration（0.5秒）
        │
        ├─ [3] Projectile 节点
        │     ├─ ProjectileHandler.Execute() → 生成火球预制体
        │     ├─ 设置目标位置
        │     └─ 等待飞行时间
        │
        ├─ [4] Effect 节点
        │     └─ EffectHandler.ExecuteSync() → 播放爆炸特效和音效
        │
        ├─ [5] AoeDamage 节点
        │     └─ AoeDamageHandler.ExecuteSync() → 对范围内的敌人造成伤害
        │
        └─ [6] Sound 节点
              └─ SoundHandler.ExecuteSync() → 播放伤害音效
```

### 5.2 Buff 执行流程

Buff 的执行由 `BuffManager` 在实体每帧 `Update()` 中驱动，与技能系统独立：

```
每帧 Update():
  │
  └─ BuffManager.Update()
        │
        ├─ 遍历所有 activeBuffs
        │     ├─ BuffBase.CheckDuration()
        │     │     └─ 如果是 Duration 类型：检查 elapsed >= duration
        │     ├─ 如果是 Dot/Hot：每 interval 秒触发一次效果
        │     └─ BuffBase.AddEffectuateCount()
        │
        └─ 移除已过期的 Buff
```

```csharp
public Vector3 GetParamVector3(string key, Vector3 defaultValue = default)
{
    if (!_params.TryGetValue(key, out var value))
        return defaultValue;

    var parts = value.Split(',');
    if (parts.Length != 3) return defaultValue;

        float.Parse(parts[0]),
        float.Parse(parts[1]),
        float.Parse(parts[2])
    );
}
```

### 7.5 Luban 表格集成

`SkillConfig`（Luban兼容）与 `SkillGraphConfig`（节点图）分离：

- `SkillConfig`：由 Luban 导出，包含技能基础数据（伤害、冷却、消耗等）
- `SkillGraphConfig`：包含技能的行为逻辑（节点图）

典型使用方式：

```csharp
var skillConfig = LubanLoader.LoadSkillConfig(skillId);

var context = new SkillContext
{

    Level = skillConfig.Level,
    Caster = caster,
    Target = target,
    Config = skillGraph
};

await executor.Execute(skillGraph, context);
```

## 八、已知限制与待办

1. **BranchHandler 分支**: 条件分支目前仅判断执行条件，但不会实际跳过节点执行，后续需要支持 `Branch` 节点有条件地仅执行"是"/"否"分支的输出边

2. **Buff节点图执行**: Buff系统目前没有实现 `BuffNodeExecutor`，Buff图的遍历执行尚未集成到 `BuffManager` 中

3. **投掷物碰撞**: 目前通过飞行时间判断命中，后续需要实现物理碰撞检测

4. **多目标支持**: 当前 `AoeDamage` 仅处理单一目标位置，后续需要支持多目标选择策略（最近、HP最低等）

5. **节点组/子图**: 不支持将多个节点打包为可复用的子图

6. **循环边**: 虽然有 `HashSet` 防重执行，但包含循环的图可能导致意外行为
