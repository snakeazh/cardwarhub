# 技能与Buff节点图系统 — 策划配置文档

> **文档版本**: 1.0.0
> **最后更新**: 2026-03-19
> **适用项目**: FusionContinent (CardWar 1.9)
> **阅读对象**: 策划、关卡设计师

---

## 一、系统概述

本系统采用**节点图（Node Graph）**架构，将技能和Buff的行为拆解为可组合的节点，通过连线表示执行顺序。策划通过配置节点的参数来定义技能效果，无需编写代码。

### 1.1 核心概念

| 概念 | 说明 |
|------|------|
| **节点（Node）** | 技能/Buff的最小执行单元，如"施法"、"伤害"、"特效"等 |
| **连线（Edge）** | 连接两个节点，表示执行顺序。数据从输出端口流向输入端口 |
| **端口（Port）** | 节点上的连接点，分为输入（左侧）和输出（右侧）端口 |
| **执行流（Exec）** | 特殊的执行端口，控制节点的执行先后顺序 |
| **参数（Param）** | 节点的配置数据，如伤害值、持续时间等 |

### 1.2 执行流程

```
[Cast 施法] → [Telegraph 预警] → [Projectile 投掷物] → [Effect 特效] → [AoeDamage 范围伤害] → [Sound 音效]
     ↑ exec_out         ↑ exec_out          ↑ exec_out           ↑ exec_out           ↑ exec_out
```

节点的执行顺序由连线决定。上游节点执行完毕后，沿着 `exec_out` 端口触发下游节点的执行。

## 二、技能节点配置

### 2.1 节点类型总览

| 节点类型 | 中文名 | 分类 | 说明 |
|---------|--------|------|------|
| `Cast` | 施法 | 流程控制 | 播放施法动画，等待引导时间 |
| `Telegraph` | 预警 | 视觉效果 | 在目标位置显示预警指示器 |
| `Projectile` | 投掷物 | 伤害 | 生成并发射投射物到目标位置 |
| `AoeDamage` | 范围伤害 | 伤害 | 对指定范围内的所有敌人造成伤害 |
| `Delay` | 延迟 | 流程控制 | 暂停执行指定时间 |
| `Effect` | 特效 | 视觉效果 | 播放视觉特效（VFX）和音效（SFX） |
| `Sound` | 音效 | 视觉效果 | 仅播放音效 |
| `ApplyBuff` | 施加Buff | Buff | 为目标添加一个Buff效果 |
| `Branch` | 条件分支 | 流程控制 | 根据条件判断决定是否执行后续节点 |

---

### 2.2 Cast（施法节点）

> **功能**: 触发技能的施法动作和引导时间。是技能图的**入口节点**，每个技能图必须有一个Cast节点作为起点。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `animation` | string | `"Attack"` | 任意动画名称 | 播放的动画名称，需与Animator中的动画名称一致 |
| `cast_time` | float | `0.3` | ≥ 0 | 引导时间（秒），0表示瞬发不等待 |
| `move_speed` | float | `0` | 0 ~ 1 | 施法时移动速度倍率，0表示禁止移动 |

**示例配置**:

```
animation   = "FireMagic"
cast_time   = 1.5      → 引导1.5秒后释放
move_speed  = 0        → 施法时禁止移动
```

### 2.3 Telegraph（预警节点）

> **功能**: 在目标位置显示预警指示器，告知玩家技能即将释放的范围和时机。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `shape` | string | `"Circle"` | `Circle` / `Rectangle` / `Fan` | 预警形状 |
| `range` | float | `3` | > 0 | 预警范围大小（米） |
| `duration` | float | `0.5` | ≥ 0 | 预警显示持续时间（秒） |
| `color` | string | `"#FF4400"` | Hex颜色码 | 预警区域颜色，如 `"#FF3300"` 表示红色 |

**shape 取值说明**:

| 值 | 说明 | 额外参数 |
|----|------|---------|
| `Circle` | 圆形区域 | `range` 为半径 |
| `Rectangle` | 矩形区域 | `range` 为长/宽 |
| `Fan` | 扇形区域 | `range` 为半径，`angle` 为角度 |

**示例配置**:

```
shape     = Circle
range     = 5
duration   = 0.5
color     = #FF3300    → 红色预警圈，半径5米，持续0.5秒
```

---

### 2.4 Projectile（投掷物节点）

> **功能**: 生成并发射一个投射物到目标位置。可设置飞行速度、轨迹类型、是否追踪目标。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `prefab` | string | `""` | Resources路径 | 投掷物预制体路径，如 `"Prefabs/Projectiles/FireBall"` |
| `speed` | float | `10` | > 0 | 飞行速度（米/秒） |
| `damage` | float | `100` | ≥ 0 | 命中时的伤害值 |
| `damage_type` | string | `"Magic"` | `Magic` / `Physics` / `True` | 伤害类型 |
| `trajectory` | string | `"Straight"` | `Straight` / `Curve` | 飞行轨迹类型 |
| `homing` | bool | `false` | true / false | 是否追踪目标（锁定目标位置） |
| `max_distance` | float | `20` | > 0 | 最大飞行距离（米），超出后自动销毁 |
| `gravity` | float | `0` | ≥ 0 | 重力加速度（米/秒²），0表示无重力 |

**示例配置**:

```
prefab       = Prefabs/Projectiles/FireBall
speed        = 15
damage       = 100
damage_type  = Magic
trajectory   = Straight
homing       = false
max_distance = 20
gravity      = 0
```

### 2.5 AoeDamage（范围伤害节点）

> **功能**: 对指定范围内的所有敌人造成伤害。伤害结算为瞬时完成。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `shape` | string | `"Circle"` | `Circle` / `Rectangle` / `Fan` | 范围形状 |
| `range` | float | `3` | > 0 | 范围大小（米） |
| `damage` | float | `100` | ≥ 0 | 基础伤害值 |
| `damage_type` | string | `"Magic"` | `Magic` / `Physics` / `True` | 伤害类型 |
| `knockback` | float | `0` | ≥ 0 | 击退距离（米），0表示不击退 |
| `angle` | float | `60` | 1 ~ 360 | 扇形角度（度），仅 `shape=Fan` 时生效 |
| `range_center` | string | `"Target"` | `Target` / `Self` | 范围中心点：目标位置 或 施法者位置 |

**示例配置**:

```
damage      = 80
damage_type = Magic
shape       = Circle
range       = 5
knockback   = 2          → 将命中的敌人击退2米
```

### 2.6 Delay（延迟节点）

> **功能**: 暂停执行指定时间，常用于引导效果、分段施法。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `duration` | float | `1` | ≥ 0 | 延迟时间（秒） |

**示例配置**:

```
duration = 0.5    → 等待0.5秒后继续执行后续节点
```

---

### 2.7 Effect（特效节点）

> **功能**: 播放视觉特效（VFX）和/或音效（SFX）。

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `vfx` | string | `""` | VFX 预制体路径（Resources路径），如 `"Prefabs/VFX/Explosion"` |
| `sfx` | string | `""` | SFX 音频路径 |
| `position` | string | `"Target"` | 特效播放位置：`Target`（目标位置）/ `Self`（施法者位置） |

**示例配置**:

```
vfx       = Prefabs/VFX/Explosion
sfx       = Audio/SFX/Explosion
position  = Target        → 在目标位置播放爆炸特效和音效
```

---

### 2.8 Sound（音效节点）

> **功能**: 仅播放音效，不生成视觉特效。适合与特效节点配合使用（先播视觉再播音效）。

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `sound` | string | `""` | SFX 音频路径 |
| `volume` | float | `1` | 音量（0 ~ 1） |
| `pitch` | float | `1` | 音调倍率 |
| `loop` | bool | `false` | 是否循环播放 |

**示例配置**:

```
sound  = Audio/SFX/Impact
volume = 0.8
pitch  = 1.0
```

---

### 2.9 ApplyBuff（施加Buff节点）

> **功能**: 为目标添加一个Buff效果。目标可以是当前锁定目标、施法者自身或所有目标。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `buff_id` | int | `0` | > 0 | Buff配置的ID，对应 Luban 表格中的 BuffId |
| `target` | string | `"Target"` | `Target` / `Self` / `All` | 目标类型 |
| `stack` | int | `1` | ≥ 1 | Buff叠加层数 |
| `duration` | float | `-1` | ≥ -1 | 持续时间（秒），-1表示永久 |
| `effect_value` | float | `0` | 任意 | Buff效果值（由Buff定义决定是否使用） |
| `probability` | float | `1` | 0 ~ 1 | 触发概率，1表示必定触发 |
| `duration_type` | string | `"Once"` | `Once` / `Duration` | 持续类型 |

**duration_type 说明**:

| 值 | 说明 |
|----|------|
| `Once` | 一次性生效，添加后立即触发效果 |
| `Duration` | 持续时间型，在整个持续时间内周期性生效（由Buff定义） |

**示例配置**:

```
target        = Target
buff_id       = 1001     → 对应"燃烧"Buff
stack         = 1
duration      = 5        → 持续5秒
duration_type = Duration
effect_value  = 50
probability   = 1        → 100%触发
```

### 2.10 Branch（条件分支节点）

> **功能**: 根据条件判断决定后续节点的执行。条件为真时正常执行，为假时跳过。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `condition` | string | `"TargetAlive"` | 见下表 | 条件类型 |
| `probability` | float | `0.5` | 0 ~ 1 | 随机概率（仅 `Random` 条件时使用） |
| `compare_value` | float | `0` | 0 ~ 1 | 比较值（仅特定条件时使用） |

**condition 可选值**:

| 值 | 说明 | 额外参数 |
|----|------|---------|
| `TargetAlive` | 目标存在且存活 | — |
| `Random` | 随机概率 | `probability`（0~1） |
| `TargetIsMonster` | 目标是怪物 | — |
| `TargetIsSoldier` | 目标是士兵 | — |
| `HpLessThan` | 目标HP低于指定百分比 | `compare_value`（0~1，如0.3=30%） |
| `HpGreaterThan` | 目标HP高于指定百分比 | `compare_value`（0~1） |
| `AlwaysTrue` | 始终为真（无条件通过） | — |
| `AlwaysFalse` | 始终为假（跳过所有后续） | — |

**示例配置**:

```
condition     = TargetAlive     → 目标存活时才执行后续节点
```

```
condition     = Random
probability   = 0.3             → 30%概率继续执行
```

```
condition     = HpLessThan
compare_value = 0.3             → 目标HP低于30%时触发
```

## 三、Buff节点配置

### 3.1 节点类型总览

| 节点类型 | 中文名 | 说明 |
|---------|--------|------|
| `OnApply` | 应用时触发 | Buff被添加到目标时立即触发一次 |
| `OnTick` | 周期触发 | Buff以固定间隔周期性触发效果 |
| `OnRemove` | 移除时触发 | Buff被移除时触发（手动移除或持续时间结束） |
| `Dot` | 持续伤害 | 周期性对目标造成伤害（Damage Over Time） |
| `Hot` | 持续治疗 | 周期性恢复目标生命值（Heal Over Time） |
| `Shield` | 护盾 | 为目标提供一个临时护盾，吸收伤害 |
| `Vulnerable` | 易伤 | 目标受到的伤害增加 |
| `Slow` | 减速 | 降低目标的移动速度 |
| `Effect` | 特效 | 播放视觉/音效特效 |

### 3.2 OnApply（应用时触发）

> **功能**: Buff被添加到目标时立即触发一次。常用于添加Buff时的即时效果（如护盾、属性变化）。

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `buff_name` | string | `""` | Buff显示名称（仅编辑器使用，方便策划识别） |

**示例配置**:

```
buff_name = 护盾       → 名称仅供编辑器显示
```

### 3.3 OnTick（周期触发）

> **功能**: Buff以固定间隔周期性触发效果。常配合 Dot/Hot 节点使用，定义周期性生效的间隔。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `interval` | float | `1` | > 0 | 触发间隔（秒），如设为1则每秒触发一次 |

**示例配置**:

```
interval = 1    → 每1秒触发一次Dot/Hot效果
```

### 3.4 OnRemove（移除时触发）

> **功能**: Buff被移除时触发一次。常用于移除Buff时的清理效果（如移除属性加成、显示消散特效）。

**无参数。**

### 3.5 Dot（持续伤害）

> **功能**: 周期性对目标造成伤害。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `damage` | float | `10` | 任意 | 每次触发的伤害值 |
| `interval` | float | `1` | > 0 | 触发间隔（秒） |
| `damage_type` | string | `"Magic"` | `Magic` / `Physics` / `True` | 伤害类型 |

**示例配置**:

```
damage       = 10
interval     = 1
damage_type  = Magic    → 每秒造成10点魔法伤害
```

```
damage       = 5
interval     = 0.5
damage_type  = Magic    → 每0.5秒造成5点魔法伤害（每秒共10点）
```

### 3.6 Hot（持续治疗）

> **功能**: 周期性恢复目标生命值。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `heal` | float | `10` | 任意 | 每次触发的治疗量 |
| `interval` | float | `1` | > 0 | 触发间隔（秒） |

**示例配置**:

```
heal     = 20
interval = 2       → 每2秒恢复20点生命（平均每秒10点）
```

### 3.7 Shield（护盾）

> **功能**: 为目标提供一个临时护盾，吸收伤害。护盾优先于真实生命值承受伤害。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `shield_value` | float | `100` | ≥ 0 | 护盾可吸收的伤害总量 |
| `shield_type` | string | `"Normal"` | `Normal` / `Magic` / `Physics` | 护盾类型 |

**shield_type 说明**:

| 值 | 说明 |
|----|------|
| `Normal` | 普通护盾，吸收所有类型伤害 |
| `Magic` | 仅吸收魔法伤害 |
| `Physics` | 仅吸收物理伤害 |

**示例配置**:

```
shield_value = 200
shield_type  = Normal    → 提供200点普通护盾
```

```
shield_value = 100
shield_type  = Magic     → 提供100点魔法护盾（只挡魔法伤害）
```

### 3.8 Vulnerable（易伤）

> **功能**: 目标受到的伤害增加。实际伤害乘数在战斗系统中计算。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `damage_increase` | float | `0.3` | 0 ~ 1 | 受伤增加比例（0.3 = 受到伤害增加30%） |

**示例配置**:

```
damage_increase = 0.3     → 受到伤害增加30%
```

```
damage_increase = 0.5     → 受到伤害增加50%（重伤）
```

### 3.9 Slow（减速）

> **功能**: 降低目标的移动速度。

| 参数名 | 类型 | 默认值 | 取值范围 | 说明 |
|--------|------|--------|---------|------|
| `speed_reduce` | float | `0.5` | 0 ~ 1 | 速度降低比例（0.5 = 降低50%速度） |

**示例配置**:

```
speed_reduce = 0.5        → 移动速度降低50%
```

```
speed_reduce = 0.3        → 移动速度降低30%（轻微减速）
```

### 3.10 Effect（特效）

> **功能**: 播放视觉/音效特效。常用于Buff添加时和移除时的视觉反馈。

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `vfx` | string | `""` | VFX 预制体路径 |
| `sfx` | string | `""` | SFX 音频路径 |
| `position` | string | `"Target"` | 特效位置：`Target`（目标）/ `Self`（Buff持有者） |

## 四、技能组合示例

### 示例1：火球术（标准远程技能）

```
Cast(1.0s) → Telegraph(Circle, 5m, 0.5s) → Projectile → Effect(爆炸) → AoeDamage(Circle, 3m, 80) → Sound(冲击)
```

| 节点 | 参数配置 |
|------|---------|
| Cast | animation="Fire", cast_time=1.0 |
| Telegraph | shape="Circle", range=5, duration=0.5, color="#FF4400" |
| Projectile | prefab="Prefabs/Projectiles/FireBall", speed=15, damage=100 |
| Effect | vfx="VFX/FireExplosion", sfx="Audio/FireExplosion" |
| AoeDamage | shape="Circle", range=3, damage=80, knockback=2 |
| Sound | sound="Audio/Impact" |

### 示例2：闪电链（带Debuff）

```
Cast(0.5s) → Effect(闪电) → AoeDamage(Circle, 2m, 60) → Delay(0.3s) → ApplyBuff(麻痹Debuff)
```

| 节点 | 参数配置 |
|------|---------|
| Cast | animation="Magic", cast_time=0.5 |
| Effect | vfx="VFX/Lightning", sfx="Audio/Lightning" |
| AoeDamage | shape="Circle", range=2, damage=60 |
| Delay | duration=0.3 |
| ApplyBuff | buff_id=1008, target="Target", duration=3 |

### 示例3：引导爆发（带两段预警）

```
Cast(2.0s) → Telegraph(Circle, 4m, 0.8s) → Delay(1.2s) → Telegraph(Circle, 4m, 0.3s) → AoeDamage(Circle, 4m, 200)
```

### 示例4：治疗术

```
Cast(0.5s) → Effect(治疗开始) → Delay(0.3s) → Effect(治疗结束)
```

### 示例5：带条件的追击技能

```
Cast(0.3s) → Branch(HpLessThan) ─[true]→ AoeDamage(大范围) → Effect(终结特效)
                            └[false]→ AoeDamage(小范围)
```

## 六、节点连线规则

### 6.1 连线基本原则

1. **exec 端口只能连接 exec 端口**: 节点只有 `exec_in` 和 `exec_out` 两种执行端口，它们之间互相连接
2. **数据端口用于数据传递**（未来扩展）: 未来可能添加 `Flow` / `Data` 类型端口
3. **连线方向**: 从上游节点的 `exec_out` 指向下游节点的 `exec_in`

### 6.2 入口节点

- **技能**: 入口节点必须是 `Cast`。技能图从 Cast 节点开始执行。
- **Buff**: 入口节点是 `OnApply`（添加时触发）、`OnTick`（周期触发）、`OnRemove`（移除时触发）之一。

### 6.3 节点端口对照表

**技能节点端口**:

| 节点类型 | 输入端口 | 输出端口 |
|---------|---------|---------|
| Cast | — | exec_out |
| Telegraph | exec_in | exec_out |
| Projectile | exec_in | exec_out |
| AoeDamage | exec_in | exec_out |
| Delay | exec_in | exec_out |
| Effect | exec_in | exec_out |
| Sound | exec_in | exec_out |
| ApplyBuff | exec_in | exec_out |
| Branch | exec_in | exec_out × 2（true/false） |

**Buff节点端口**:

| 节点类型 | 输入端口 | 输出端口 |
|---------|---------|---------|
| OnApply | — | exec_out |
| OnTick | — | exec_out |
| OnRemove | — | exec_out |
| Dot | exec_in | exec_out |
| Hot | exec_in | exec_out |
| Shield | exec_in | exec_out |
| Vulnerable | exec_in | exec_out |
| Slow | exec_in | exec_out |
| Effect | exec_in | exec_out |

### 8.2 SkillGraphConfig 与 Luban 表的对应关系

- **Luban TbSkill**: 定义技能的基础元数据（ID、名称、冷却、消耗等），不包含行为逻辑
- **SkillGraphConfig**: 定义技能的行为逻辑（节点图），通过 `SkillId` 字段关联 Luban 表

运行时使用示例：

```csharp
// 1. 从Luban加载技能元数据
var skillMeta = LubanLoader.LoadSkillConfig(skillId);

// 2. 加载技能节点图（行为逻辑）
var skillGraph = Resources.Load<SkillGraphConfig>($"SkillGraphs/{skillId}");

// 3. 创建执行上下文
var context = new SkillContext {
    SkillId = skillMeta.SkillId,
    Caster = caster,
    Target = target,
};

// 4. 执行
await executor.Execute(skillGraph, context);
```

## 九、常见问题

### Q1: 技能没有按预期执行？

**排查步骤**:
1. 检查节点之间的连线是否正确连接（exec_out → exec_in）
2. 检查是否有未连接的输入端口，导致节点孤立
3. 查看 Console 日志，确认节点执行顺序

### Q2: 预警显示的位置不对？

检查 `AoeDamage` 节点的 `range_center` 参数：
- `Target`: 以锁定目标为中心
- `Self`: 以施法者为中心

### Q3: Buff没有生效？

检查 `ApplyBuff` 节点的参数：
- `buff_id` 是否正确（对应 Luban 表中的 ID）
- `target` 是否正确（`Target` = 当前目标，`Self` = 施法者）
- `probability` 是否小于 1（可能是概率未触发）

### Q4: 投射物没有命中目标？

- 检查 `max_distance` 是否足够大
- 检查 `speed` 是否合理（速度太慢可能目标已离开）
- 检查目标引用是否为空（`context.Target`）

### Q5: 分支条件没有按预期工作？

当前版本的 `Branch` 节点会执行所有后续节点。条件判断结果可通过 `SkillContext.SetExtraData()` 传递给后续节点使用。具体行为由程序实现决定。
